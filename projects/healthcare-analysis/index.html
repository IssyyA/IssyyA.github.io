Project Overview

This project analyzes healthcare performance data from US hospitals, focusing on patient admissions, billing patterns, and demographic information. The interactive Power BI dashboard provides insights into hospital operations, financial performance, and patient characteristics.

The analysis covers data from January 2019 to December 2024, offering a comprehensive view of healthcare trends during this period. Key metrics include total patient volume, billing amounts, average length of stay, and most common medical conditions.

Dataset Description

The dataset comprises multiple tables capturing patient admissions, billing records, and demographic information from various hospitals and insurance providers. The data model is structured as a star schema with the following components:

Data Model Structure

Key Tables

Fact Hospital

The central fact table containing patient admission details including billing amounts, dates, length of stay, and hospital information.

Dim Patient

Patient demographic information including age, gender, blood type, and insurance provider.

Dim Hospital

Hospital information including names and geographic coordinates.

DateTable

Date dimension for temporal analysis with month, quarter, and year information.

Analysis Approach

The analysis followed a structured approach to transform raw healthcare data into actionable insights:

1

Data Cleaning

Initial data cleaning and transformation using Power Query to ensure data quality and consistency.

2

Data Modeling

Creation of a star schema data model with proper relationships between fact and dimension tables.

3

DAX Measures

Development of calculated measures and KPIs using DAX for comprehensive analysis.

4

Visualization

Design of interactive visualizations in Power BI to present the data insights effectively.

Example DAX Measures

Total Patients = DISTINCTCOUNT(Fact_Hospital[Patient ID])

Total Billing Amount = SUM(Fact_Hospital[Billing Amount])

Avg Length of Stay = AVERAGE(Fact_Hospital[Length of Stay])

Key Insights

The analysis revealed several important findings about healthcare performance:

Patient Demographics

The 20-29 age group represented the highest patient volume, with significant gender distribution differences across conditions.

Hospital Performance

Houston Hospital and Johns Hopkins managed the highest patient volumes and billing amounts, indicating their major roles in the healthcare system.

Seasonal Patterns

Patient admissions showed clear quarterly trends, typically peaking in Q3, which has implications for staffing and resource planning.

Condition Prevalence

Hypertension emerged as the most common medical condition, followed by diabetes and obesity-related issues.
